# 第 2 章 操作系统
一个观点、两条线索：一个观点以资源管理的观点来定义操作系统，两条线索是指操作系统如何管理计算机各类资源和控制程序的执行。

## 2.1 操作系统的类型与结构

计算机系统由硬件和软件两部分组成。操作系统是计算机系统中最基本的系统软件。它即管理计算机的软硬件资源，又控制程序的执行。

操作系统基本类型：

- 批处理操作系统
- 分时操作系统
- 实时操作系统

从资源管理的角度看，操作系统主要是对处理器、存储器、文件、设备和作业进行管理。


### 2.1.1 操作系统的定义

操作系统（Operating System，OS）是计算机系统中的核心系统软件，负责管理和控制计算机系统中的硬件和软件资源，合理地组织计算机工作流程和有效地利用资源，在计算机和用户之间起接口的作用。操作系统为用户提供的接口表现形式一般为：命令、菜单、窗口之类的，而操作系统为应用程序提供的接口为 API。

### 2.1.2 操作系统分类

按照操作系统的功能划分，操作系统的基本类型有批处理操作系统、分时操作系统、实时操作系统、网络操作系统、分布式操作系统、嵌入式操作系统、微内核操作系统等。


## 2.2 操作系统基本原理

操作系统的主要功能是进行处理机与进程管理、存储管理、设备管理、文件管理和作业管理的工作。

### 2.2.1 进程管理

处理机是计算机系统的核心资源。操作系统的功能之一就是处理机管理。处理机的充分利用有利于系统效率的大大提高。处理机管理是整个操作系统的重心所在，其管理的好坏直接影响到整个系统的运行效率。操作系统中并发活动的管理和控制是在处理机管理下实现的。处理机管理集中了操作系统中最复杂的部分，它设计的好坏关系到整个系统的成败。

进程是处理机管理中最基本的、最重要的概念。进程是系统并发执行的体现。由于在多道程序系统中，众多计算机用户都以各种各样的任务，随时随地争夺使用处理机，为了动态的看待操作系统，则以进程作为独立运行的基本单位，以进程作为分配资源的基本单位，以进程的角度来研究操作系统。因此处理机管理也被称为进程管理。处理机管理的功能就是组织和协调用户对处理机的争夺和使用，把处理机分配给进程，对进程进行管理和控制，最大限度发挥处理机的作用。

#### 进程的概念

用静态的观点来看，操作系统是一组程序与表格的集合。用动态的观点看，操作系统是进程动态和并发执行的。

顺序程序是指程序中若干操作必须按照某种先后顺序来执行。并且每次操作前和操作后的数据、状态之间有一定的关系。在早期的程序设计中，程序一般都是按顺序执行的。

在多道程序系统中，程序的运行环境发生了很大变化：

1. 资源共享，为了提高资源利用率，计算机中的资源不再由一道程序专用，而是由多道程序共同使用。
2. 程序的并发执行或并行执行。逻辑上允许多道不同用户的程序并行执行。允许一个用户程序内部不同操作的程序段之间并行运行。允许操作系统内部不同程序之间并行运行。物理上讲，内存存储器中保存多个程序，I/O 设备被多个程序交替的共享使用，在多处理机系统的情形下，表现为多个程序在各自的处理机上运行。执行时间是重叠的。单处理机系统时，程序的执行表现为多道程序交替的在处理机上相互空插运行。

#### 进程的状态转化

由进程运行的间断性，决定了进程至少有以下三种状态
- 就绪状态：已经分配了除 cpu 以外的所有资源，只要能再获得处理机便能立即。一个系统中可以有多个就绪状态的进程，通常将他们排成一个队列，叫就绪队列。
- 执行状态：已获得处理机正在执行。
- 阻塞状态：因进程发生事件（如IO或者申请缓存区）而暂停执行时的状态，也叫暂停状态或等待状态。处于阻塞状态的队列也组成一个队列，叫阻塞队列。
- 挂起状态：对换的需要、缓解内存紧张。终端用户请求、父进程请求、负荷调节的必要、操作系统的需要。

#### 进程互斥与进程同步

进程互斥：一组进程中一个或多个程序段，因为共有资源导致在同一时刻只能被一个进程访问。
进程同步：异步环境下的一组进程因直接制约关系互相发送消息进而进行互相合作、互相等待，使得各进程按一定的速度执行的过程为进程同步。

系统中有些资源可以供多个进程使用，而有些资源同时只能被一个进程使用。将一次性只能被一个进程使用的资源称为临界资源。很多物理设备：如打印机、磁带等。某些软件的变量数据和表格也不允许多个进程使用，所以也是临界资源。

把一个进程访问临界资源的代码称为临界区。

1. 空闲让进
2. 忙则等待
3. 有限等待
4. 让权等待，等待进入临界区的资源必须释放其占有的 CPU 资源。信号量可以有效地实现进程的同步与互斥。在操作系统中，信号量是一个整数，当信号量大于 0 时代表可供并发进程使用的资源实体数，当信号量小于 0 时，则表示正在等待区的进程数，

对信号量只能实施特殊的操作 P 操作 和 V 操作，P 与 V 都是不可分割的原子操作。

P（sem）操作的过程是将信号量 sem 值减 1，若 sem 的值成负数，则调用 P 操作的进程暂停执行，直到另一个进程对同一信号量做 V 操作。 V（sem）操作的过程是将信号量 sem 的值加 1，若 sem 的值小于等于 0，从相应队列中选一个进程唤醒它。

经典同步问题的例子是“生产者-消费者”问题。这要求存后再取，取后再存，即有两个制约关系，为此需要两个信号量，表示缓存区的空单员数和非空单元数，记为 Bufempty 和 Bufful，它们的初值值分别是 1 和 0，相应的程序段形式是：

生产者

loop
生产-产品 next；
P(Bufempty); -- 等待空闲资源
next 产品缓存区；-- 存入产品
V(Buffull); -- 释放资源
endloop

消费者

loop
P(Buffull); -- 等待非空资源
取产品缓存区；-- 取出产品
V(Bufempty); -- 释放资源
endloop

#### 进程调度与死锁

进程调度即处理器调度（又称上下文转换），它的主要功能是确定再什么时候分配处理器,并确定分配给哪一个进程，即让正在执行的进程暂停执行转入就绪队列的队尾，再由调度原语将就绪队列进程取出，投入执行。

引起进程调度的原因有以下几类

- 正在执行的进程执行完毕
- 执行中的进程调用阻塞原语将自己阻塞进入睡眠状态
- 执行中的进程调用了 P 原语，资源不足阻塞，或调用 V 原语激活了等待资源的队列。
- 在分时系统中，当一个进程用完一个时间片。
- 就绪队列中某进程的优先级高于当前执行进程的优先级。

进程调度方式有两类：剥夺方式与非剥夺方式。

先来先服务调度算法：就绪队列按先来后到排序
优先数调度：就绪队列按优先数排序
轮转法：就绪队列按 先来先服务排队，使用完分配的时间片后，释放处理机到就绪队列队尾排队。

死锁

死锁是系统的一种出错状态，它不仅会浪费大量的系统资源，甚至还会导致整个系统的奔溃。所以死锁时应该尽量预防和避免的。
（1）死锁条件，主要原因是共享的系统资源不足，资源分配策略和进程的推进顺序不当。系统资源即可能是可重复使用的永久性资源，也肯能是消耗性的临时资源，产生死锁的必要条件：互斥条件、保持和等待条件、不剥夺条件和环路等待条件。
（2）解决死锁的策略，处于死锁状态的进程不能继续执行又占用了系统资源，从而阻碍其他作业执行。
解决死锁有两种策略一种是在发生前采用预防和避免策略；另一种是在死锁发生后采用的检测与恢复策略。

预防：资源静态分配法或有序分配法。会大大降低资源利用率和进程之间的并行程度。
死锁避免策略，则进行资源分配时先进行死锁避免算法（如银行家算法）。资源分配很频繁，因此要消耗大量测 cpu 和时间。

### 存储管理

存储器时计算机中最重要的资源之一。因为任何程序和数据以及各种控制用的各种数据结构都必须占有一定的存储空间，因此存储管理直接影响系统性能。

存储器由内存和外存组成，内存是由系统实际提供的存储单元组成的一个连续地址空间，处理器可直接存取。外存指软盘、硬盘、磁带和光盘一些外部存储设备。常用来存放不执行的程序和数据。处理器不能直接访问外存，需通过启动 I/O 设备才能进行内存外存交换，但价格便宜。

系统内存一般分为两部分，一个是系统空间，存放操作系统本身及相关系统程序。二是用户空间，存放用户的程序和数据。

1. 页式存储管理：分页的基本思想是把程序的逻辑空间与内存的物理空间按照同样的大小划分成若干页面，并以页面为单位进行分配。在页式存储管理中，系统中虚地址是一个有序对（页号，位移）。系统会为每一个进程建立一个页表，其内容包括进程内逻辑页号与物理页号的对应关系状态等。

页表基址寄存器（PTBR）

页式系统的动态地址转换是这样进行的，当进程运行时，其页表的首地址已保存在系统的动态地址转换机构中的基本地址寄存器中。执行的指令访问虚存（d，p）时，首先根据页号 p 查页表，由状态可知这个页是否已经调入内存，则得到该页的内存地址 p' 。然后与页内对应的相对位移 d 组合，得到物理地址 r，如果该页尚未调入内存，则产生缺页中断，以装入所需的页。

页面调度算法
- 最优算法：选择不再使用或者最远的将来才使用的。
- 随机算法：随机淘汰。
- 先进先出算法：淘汰最早调入的内存。
- 最近最少使用算法：当前最近一段时间内使用最少的页面。

2. 段式存储管理
 
 段式存储管理与页式存储管理相似，分段的基本思想是把用户作业按逻辑意义上有完整意义的段来划分，并以段为单位作为内外存交换的空间尺度。

 段表包含
1. 段号、段长、基址
2. 虚地址（段号、位移）
3. 物理地址：基址、位移

分段系统的动态地址转换是这样进行的，进程执行时，其段表的首地址已在基本地址寄存器中。指令的指令访问虚存（s, d）时，首先根据段号 s 查段表，若段已调入内存，则得到该段的内存起始地址，然后与段内相对地址相加，得到实际地址。如果该段尚未装入内存则产生缺页中断。以装入需要的段。


3. 段页式存储管理

段页式管理是段式和页式两种方法结合的产物，综合页段式组织与页式组织的特点。根据程序模块分段，段内再分页，内存被划分成定长的页。段页式系统中的虚地址是（段号、页号、页内偏移）。系统为每个进程建立一个段表，为每个段表建立一个页表。采用段式分配、页式使用的方法。

段页式虚拟存储管理。

### 设备管理

#### 设备传输控制方式

设备管理的主要任务之一是控制设备和内存或 CPU 之间的数据传送，本节介绍几种常用的数据传送控制方式。

选择和衡量控制方式的原则：
1. 传输速度足够，满足需要不丢失数据
2. 系统开销小，所处理的控制程序少
3. 充分发挥硬件资源，设备尽量处于使用中，减少 CPU 等待。

外围设备和聂村之间常用的数据传送控制方式主要有以下几种：
1. 程序控制方式。处理器启动数据传输，然后等设备完成。
2. 中断方式。程序控制方式不能实现并发。中断方式的数据传输过程是这样的，进程启动读取后，该进程放弃处理，当数据传输完成，设备控制产生中断请求，中断处理程序对数据传输工作处理完成之后，让该进程称为就绪状态，以后改进程就可以得到所需的数据。
3. 直接存储访问（Direct Memory Access，DMA） 方式，指外部设备和内存之间开辟数据交换通路。除了控制状态寄存器和数据缓存寄存器外，传输字节计数器、内存地址寄存器等。DMA 采用窃取或挪用处理器的工作周期和总线。
4. 通道方式，可以独立完成系统交付的输入输出任务。

#### 虚设备与 SPOOLING 技术

采用假脱机技术可以将低速独占设备改造成一种可共享的设备，而且一台物理设备可以对应若干台虚拟的同类设备。采用一组程序模拟一台设备的输入输出。

### 作业管理

从用户的角度看，作业是系统为完成一个用户的计算任务所做的工作总和。例如对用户的源程序编译、链接、运行，这其中的每一个步骤通常称为作业。

从系统的角度看，作业则是一个比程序更广的概念。它由程序数据和作业说明书组成。系统通过作业说明书控制文件形式的程序和数据，使之执行和操作。
